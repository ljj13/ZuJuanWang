# 提取试卷（组卷题页）

一个 Chrome / Edge 浏览器扩展（Manifest V3）：把学科网·组卷网（zujuan.xkw.com）的试卷页面一键提取为干净、可编辑、可打印的新页面，并支持导出 Word / PDF。

## 功能

- **学生版 / 教师版**：学生版隐藏解析，教师版展示解析（可选「解析在题后」或「解析在卷尾」）
- **8 类页面自适应提取**：上好课、试卷详情、高考/中考真题、分享试卷详情、专辑详情、组卷中心、智能组卷
- **导出 Word**：自动完成常用排版——表格满页宽、可打印边框置空（屏幕上看表格请开启 Word 的「查看网格线」）、超宽图片按页面/单元格宽度等比缩放；支持 A4 或 B4（8开横向）纸张
- **导出 PDF**：调起浏览器打印，另存为 PDF
- **音频下载**：试卷含听力音频时提供一键下载
- **作答区**：可为题目快速添加 / 删除作答空行（支持一键批量）

## 安装（开发者模式加载）

1. 下载或克隆本仓库到本地
2. 打开浏览器的扩展管理页：Chrome 地址栏输入 `chrome://extensions`（Edge 为 `edge://extensions`）
3. 打开右上角「开发者模式」
4. 点击「加载已解压的扩展程序」，选择本仓库文件夹
5. 工具栏出现「提取试卷」图标即安装成功

## 使用

1. 打开组卷网的一份试卷页面
2. 点击扩展图标，选择学生版 / 教师版（教师版可选解析位置），点「提取试卷」
3. 在弹出的新页面中预览、编辑标题，点「导出Word」或「下载PDF」

> 提示：导出的 Word 中表格默认不带边框（打印更干净）。在 Word 中选中表格后点「布局 → 查看网格线」，即可在屏幕上看到虚框辅助编辑，该设置打开一次后 Word 会记住。

## 隐私

- 不收集、不上传任何数据，无统计、无联网校验
- 仅在你主动「导出Word」时，扩展会访问试卷图片所在的 CDN 域名（xkw.com / zujuan.com）把图片内联进文档，使导出文件不依赖远程图链
